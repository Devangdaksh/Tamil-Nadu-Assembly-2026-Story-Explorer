# Tamil-Nadu Assembly 2026 Story Explorer

A professionally designed analysis and visualization project for Tamil Nadu Assembly elections, focused on neutral, ECI-based insights to support media planning and constituency-level strategy.

## Live Story Explorer
- Streamlit app: https://gjwc2bojilennpk8urjsnl.streamlit.app/

## Project Summary
This repository compares the Tamil Nadu Assembly election results from 2021 and 2026 through an interactive, constituency-level dashboard. It includes:

- Comparative analysis of election outcomes by year
- Interactive filtering by region and reservation status
- Constituency-level performance and trend insights
- Data-driven support for planning and reporting

## Key Features
- Clean, neutral presentation of ECI election data
- Side-by-side comparison of 2021 and 2026 results
- Region and reservation filters for targeted analysis
- Streamlit-based interactive storytelling

## Contents
- `data/` — election results and constituency reference data
- `src/` — data loading and preprocessing utilities
- `dashboard/` — Streamlit application source
- `analysis/` — scripts for generating reports and insights

## Getting Started
1. Install dependencies from `requirements.txt`.
2. Run the Streamlit dashboard from `dashboard/app.py`.
3. Use the live app link above for immediate access.
